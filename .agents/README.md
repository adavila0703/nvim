# .agents

Shared, tool-agnostic files for coding agents working on this repo.

- Repo-wide rules live in `../AGENTS.md`. Read that first.
- Put reusable prompts, task recipes, or skills here, one Markdown file each, for example `add-lsp-server.md`.
- Keep files in this folder agent-neutral. Claude-only material goes in `../CLAUDE.md` or `../.claude/`.
